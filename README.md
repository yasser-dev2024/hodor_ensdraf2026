# الحضور والانصراف الصباحي للطلاب

تطبيق Flutter عربي يعمل محليًا على Android وiOS لتسجيل الحضور والغياب والاستئذان عبر QR، مع صورة واضحة للطالب، وإدارة الطلاب والفصول، والاستيراد، والتقارير والنسخ الاحتياطي.

## الوظائف الرئيسية

- إقرار استخدام واضح ثم طلب الأذونات اللازمة فقط، دون شاشة تفعيل تعطل الدخول.
- قاعدة SQLite محلية بقيود فريدة ومعاملات وفهارس.
- تشفير السجل المدني بـ AES-256-GCM، وفهرسته ببصمة HMAC بدل تخزينه كنص مكشوف.
- توكن QR عشوائي وفريد لا يتضمن السجل المدني.
- إضافة صورة الطالب من الكاميرا أو المعرض، وإظهارها بصورة بارزة عند المسح.
- منع التسجيل المكرر في اليوم، مع تعديل الحالة للمدير وتسجيل العملية في سجل التدقيق.
- وضع سريع للفصل يعرض المسجلين والمتبقين وأسماءهم.
- استيراد XLSX وXLS (Excel 97-2003) وPDF النصي، مع اكتشاف العناوين والمعاينة والخرائط اليدوية.
- طباعة QR لطالب أو فصل أو صف أو جميع الطلاب، مع أحجام بطاقات قابلة للضبط.
- تقارير يومية وأسبوعية وشهرية ومخصصة حسب المدرسة أو الصف أو الفصل أو الطالب بصيغتي PDF وExcel.
- إحصاءات الانضباط حسب أيام الدراسة المتوقعة، مع استثناء الإجازات وتاريخ التحاق الطالب.
- ترحيل سنوي لصف كامل إلى الصف التالي، وتعطيل صف أو مرحلة كاملة بحذف آمن دون إعادة الاستيراد أو فقد التاريخ.
- لوحة الأفضل والأكثر: أفضل طالب، الأكثر غيابًا، الأكثر استئذانًا، أفضل فصل، وأكثر فصل غيابًا.
- أرشيف PDF دائم، مشاركة عبر الهاتف وفتح WhatsApp يدويًا بقالب قابل للتعديل.
- إعداد أول مدير بحقلَي اسم المستخدم وكلمة المرور فقط، ثم دخول بكلمة المرور أو البصمة مع قفل المحاولات المتكررة وRBAC.
- نسخ احتياطية مشفرة بكلمة مرور، مع فحص checksum وSQLite integrity وإصدار المخطط قبل الاستعادة.

## إصدار Android

ملفات التوقيع الفعلية مستثناة من Git. لإنشائها محليًا مرة واحدة:

```powershell
powershell -ExecutionPolicy Bypass -File tool/generate_android_keystore.ps1
powershell -ExecutionPolicy Bypass -File tool/build_android_release.ps1
```

احفظ `android/release-key.jks` و`android/key.properties` في مكان سري وآمن؛ فقدانهما يمنع إصدار تحديثات موقعة بالمفتاح نفسه.

## إصدار iOS

المشروع مجهز داخل `ios/` مع أوصاف صلاحيات الكاميرا والصور وFace ID وملف ExportOptions نموذجي. اتبع `ios/README_RELEASE.md` للبناء والتوقيع على macOS ثم التوزيع عبر TestFlight أو Ad Hoc أو Enterprise. لا يوجد رابط IPA مباشر غير موثوق في صفحة التنزيل.

## البنية

- `lib/data`: قاعدة البيانات والمخطط.
- `lib/models`: نماذج المجال.
- `lib/repositories`: عمليات البيانات وقواعد العمل.
- `lib/services`: التشفير والاستيراد والصور والتقارير والنسخ الاحتياطي.
- `lib/features`: الشاشات حسب الميزة.
- `index.html`: صفحة التنزيل المستقلة.
- `test/`: 25 اختبارًا تشمل منع التكرار وQR والحضور والنسخ والاستعادة وضغط 5000 طالب والترحيل والتقارير.
